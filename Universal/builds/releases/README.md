# Universal release artifacts (scaffold)

No Universal GUI or standalone core tarball releases are shipped yet.

When a Universal GUI or core tarball release process is defined:

1. Add a release block to `Universal/datasets/bundle-manifest.json`.
2. Create the next `NN-vX.Y.Z/` folder here (never overwrite an existing folder).
3. Document the release in root `CHANGELOG.md` under **Build/CI** or **Code**.

Until then, this directory contains only this README.
